# Agentic-Use Diagnostics Notes

This directory stores ad-hoc investigation notes for agentic-use regressions.

Conventions:
- Use one markdown file per investigation.
- Prefix filenames with the investigation date (UTC) for sorting.
- Include a short "what failed / root cause / fix / repro" structure.
- Keep notes concise and delete stale drafts once findings are captured elsewhere.

# Stainless Setup Disabled

Stainless Python SDK generation is no longer supported for this repository.
The checked-in Python SDK is maintained without Stainless.

Do not create Stainless credentials or run SDK generation. No automated lint can
prove semantic compatibility between current OpenAPI and the legacy
Stainless-generated SDK. For intentional API changes, manually review legacy SDK
compatibility, update source-owned typed clients or compatibility adapters as
needed, and do not rely on automated SDK freshness checks.
